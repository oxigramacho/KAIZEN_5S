# KAIZEN_5S

## 📋 Descrição do Projeto
O **KAIZEN_5S** é uma ferramenta web interativa de auditoria e checklist baseada na metodologia dos 5 Sensos (Utilização, Ordenação, Limpeza, Saúde/Padronização e Autodisciplina). 

🔒 **Acesso Restrito:** O sistema foi projetado simulando um ambiente corporativo, ou seja, **o acesso é restrito exclusivamente para colaboradores de uma empresa fictícia**. Isso simula o controle de segurança em ferramentas de uso interno (intranet).

O sistema opera sob uma lógica de **pontuação regressiva**: o auditor (colaborador) inicia a avaliação com a nota máxima de **100 pontos**. Cada item de não conformidade ou falha marcado no checklist atua como uma penalidade, descontando pontos da nota total. O objetivo central é manter a **meta de 100 pontos**. Ao final da inspeção, o sistema gera um relatório detalhado indicando se o setor auditado atingiu a meta ou se precisa de correções.

---

## 🚀 Tecnologias Utilizadas
* **HTML5** - Estruturação semântica da interface de auditoria e telas de acesso.
* **CSS3** - Estilização responsiva, identidade visual da empresa fictícia e feedback dinâmico (cores de alerta para pontuações baixas).
* **JavaScript** - Lógica de validação de acesso restrito, manipulação dinâmica do checklist, cálculo da pontuação regressiva em tempo real e geração automatizada do relatório final.
